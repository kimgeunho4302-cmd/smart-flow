## 쓰는 법

- **플로우차트**: 화면 상자를 누르면 해당 페이지로 이동합니다. 상자에 마우스를 올리면 연결선이 강조되고, 단계 띠(00 개요~08 모바일)의 `＋`를 누르면 그 단계만 확대됩니다. `메뉴 이동선`을 켜면 각 화면의 '메뉴' 복귀선까지 보입니다.
- **시나리오**: 고르고 `다음 단계`를 누르면 경로가 순서대로 강조되고, 페이지 보기에서 다음에 눌러야 할 버튼에 `다음` 배지가 붙습니다.
- **페이지 와이어프레임**: 좌측 GNB·LNB와 하단 버튼이 실제 화면처럼 동작합니다. 오른쪽 패널에서 기획 근거·화면 조건·확인 필요 정책·반영 요구사항을 봅니다.
- **요구사항 23건** 버튼: 원문 요구사항 표와 매핑된 화면으로 바로 이동합니다.
